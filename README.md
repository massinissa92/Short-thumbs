# ShortThumbs 🎬

**Create YouTube Shorts thumbnails directly in your browser. No uploads, no cloud, no compromise.**

[ShortThumbs](https://shortthumbs.com) is a freemium web tool built for content creators who want fast, good-looking Shorts thumbnails without handing their images to a third-party server. Everything runs **100% client-side**, so your files stay on your device from start to finish.

> ℹ️ **Note:** ShortThumbs is a commercial SaaS product and is **not open source**. This repository exists as a public hub for feedback, bug reports, and feature requests.

## ✨ Why ShortThumbs?

- 🔒 **Privacy-first:** images are processed locally in your browser and never uploaded to any server
- ⚡ **Fast:** no waiting on uploads or downloads, just open the tool and create
- 🎯 **Built for Shorts:** designed around the vertical format and what creators actually need
- 💸 **Freemium:** start for free, upgrade only if you need more
